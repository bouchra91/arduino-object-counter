# Arduino Object Counter

## 📌 Description

This is a simple Arduino project that counts objects detected by a sensor.

Each time an object passes in front of the sensor, the Arduino increases the counter by one.

The project was created to practice working with sensors, digital inputs, and basic Arduino programming.

## 🧰 Components

* Arduino
* Object detection sensor
* Jumper wires
* Breadboard
* Optional display 

## ⚙️ How It Works

The sensor detects when an object passes in front of it.

When an object is detected, the Arduino increments the counter.

The current number of detected objects can be displayed in on a LCD display.
